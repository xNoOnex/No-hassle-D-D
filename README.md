# No-hassle-D-D

A zero-auth, peer-to-peer (WebRTC) host/client web application for running simplified tabletop RPG campaigns locally. The Dungeon Master's device serves as the offline-first host and definitive game state authority, while player devices act as simplified, card-based interface clients via QR pairing.
